## 根拠のある主張

- [confirmed / 公表で確認] 委託先ApplyNowのデータ分析ツールの脆弱性を悪用されました。契約終了後も応募者情報が残っていました。 (s2, s1; ApplyNow §1 本件の概要 / 吉野家 p.1 §1・2・p.2 §4)
- [confirmed / 公表で確認] 吉野家応募者4,998件、はなまる応募者368件、採用担当者418アカウントが対象です。件数と人数は一致しません。 (s2; p.1 §1-2 / p.2 §4)
- [confirmed / 公表で確認] 委託していたApplyNowのシステムに不正アクセスがありました。 (s3; p.1 §§1-3)
- [confirmed / 公表で確認] 橿原市の2020年度応募者313件が対象の可能性があります。件数は調査中で未確定です。画像・動画は別領域で対象外です。 (s3; p.1 §§1-3)
- [confirmed / 公表で確認] ApplyNowの不正アクセスにより、富士市の応募者情報が流出しました。 (s4; 10月7日続報 流出した個人情報 / 今後の対応)
- [confirmed / 公表で確認] 続報で815件の漏洩を確認しました。初報の約800件の可能性から更新されました。動画は対象外です。 (s4; 10月7日続報 流出した個人情報 / 今後の対応)
- [confirmed / 公表で確認] 10月9日の続報で漏えいを確認し、対象を約39万人、うちApplyNow Sign利用者を約3万人と公表しました。外部調査後に件数を確定する予定です。 (s1; 【2026.10.9 更新】■ データの漏えいの確認について / ■ 漏えいした個人データについて)

## 公表された対応

- [confirmed / 公表で確認] 経路を遮断し、脆弱性を修正。対象企業にパスワード変更を促しました。 (s2, s1; ApplyNow §4 経緯・§5 現在の対応状況および対策 / 吉野家 p.2 §4)
- [confirmed / 公表で確認] 応募者への通知と、委託先の調査結果の確認を進めます。 (s3; p.1 §§1-3)
- [confirmed / 公表で確認] 対象者へ注意喚起し、委託先と連携して管理対策を検討しています。 (s4; 10月7日続報 流出した個人情報 / 今後の対応)
- [confirmed / 公表で確認] 9月11日に企業ユーザーの管理画面パスワードを強制リセットし、不正アクセスに使われたアカウント等の無効化とデータベース接続情報の更新を実施しました。 (s1; 【2026.10.9 更新】■ 経緯 / ■ 現在の対応状況および対策)
